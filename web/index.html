内部历史字段继续使用稳定的 A/B 槽位，因此改店名不会破坏历史数据。微信支付 API 暂停使用，历史账单字段仍会保留。

管理员

批量删除经营数据

可删除连续多天，或删除一整个月。日流水、菜品、食材/佐料明细、日固定支出会一起删除；整月删除同时删除该月月度固定成本。

整套内部 Excel 覆盖另一个账本

选择目标账本并上传完整内部 Excel。服务器会先备份目标账本，然后连续确认两次才执行覆盖。

当前账本整套复制到另一个账本

不需要先下载 Excel；服务器先备份目标账本，再把当前账本的全部记录完整覆盖过去，同样要求两次确认。

Excel 账本导入与导出

所有操作只针对顶部显示的当前账本；上传前会校验工作表结构。

用户 Excel

所有账号都可以按年份下载桌面软件可打开的用户账本；只有管理员可以上传替换或合并。合并会累加金额、数量和明细，单价保留账本原值。

内部 Excel（仅管理员）

下载完整云端底稿，或上传并整体替换当前账本。此操作不会改变用户与账本的绑定。

管理当前账本

可以修改当前账本的显示名称，账本 ID 不会改变。删除前请先在用户管理中解除所有用户绑定；删除的数据无法恢复。

新增独立账本

新账本彼此完全独立；建立后可在用户管理中分配给需要使用该账本的账号。
